What the app does

Wayback is a phone web app for Block M06, Desasiswa Tekun, USM, a building where GPS can't tell floors and every hallway looks alike. You snap the sides around you, and it works out where you are. Then it walks you step by step to a room, or back to your car.

  • Locate: a photo match (CLIP, in the browser), sign reading (PaddleOCR, in the browser) and a GPS pin.
  • Route: a map of spots and links (public/data/dorm-map.json plus generated rooms), shortest path, one step per link.
  • Directions: a step picture, a compass arrow, and a 3D building with your route.
  • Firebase: stores your parking and Survey uploads, and hosts the site.

One action, end to end: “Where am I?” → directions

Reference route through the code

A reference route, not a tour you've done. Search for each anchor in your editor.

  1. wayback/app/locate/LocateFlow.tsx, search runMatch. Each photo you snap starts a sign reading straight away (addShot). runMatch runs the photo match, then keeps the screen on “READING SIGNS…” until every reading is done.
  2. wayback/lib/signText.ts, search readSignText. Turns the words the OCR read into a place: a door plate (F-6-26) becomes a room, a cube board (F6-25 - F6-28) a cube, an ARAS sign a floor. These are plain text rules, so tests/signText.test.ts can check them quickly.
  3. wayback/app/locate/LocateFlow.tsx, search function Result. Decides where you are: what you typed wins, then the sign, then the photo match. A cube board puts you at the stair corridor (boardSpot). ✓ CONFIRM calls go, which runs shortestPath and toSteps from wayback/lib/route.ts and opens the directions.

A practice to reuse

Turn “it doesn't work on my photo” into a saved test with the real photo. The cube board and the white-on-yellow door plates weren't read at first. Each photo was saved in wayback/tests/fixtures/signs/ along with the answer it should give, in wayback/tests/readSign.test.ts. That's how the switch from Tesseract to PaddleOCR, and the blue-channel second pass for door plates, could be proven on all 8 photos instead of guessed.

On any project with an agent: when something fails, hand over the real failing input and agree on what the right answer looks like. Then the fix can be checked, and it stays checked later.

Run it again

Live: wayback-m06-1626.web.app. It only gives real results at M06.

Locally: cd wayback, npm install, copy .env.local.example to .env.local and fill in the Firebase values, then npm run dev and open http://localhost:3000.

Checks and deploy

npm test runs the fast tests. npm run check:ocr reads the real sign photos. npm run build then firebase deploy --only hosting publishes the site.
